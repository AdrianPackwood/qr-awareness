# QR Awareness Page

A simple full-screen page displaying the "Scan Smart" QR code security awareness poster.
Hosted on GitHub Pages and linked via Short.io for scan tracking.

## Setup

1. Save your poster image as `scan-smart.png` in this folder
2. Create a new repo on GitHub (e.g. `qr-awareness`)
3. Push this folder to the repo
4. Enable GitHub Pages: Settings → Pages → Source: main branch → Save
5. Your page will be live at `https://yourusername.github.io/qr-awareness/`

## QR Code Flow

```
QR Code → Short.io tracked link → GitHub Pages (this poster)
QR Code → Short.io tracked link → YouTube rickroll
```

## Tracking

Short.io provides analytics on each scan:
- Timestamp
- Device type
- Location (country/city)
- Referrer

Check your Short.io dashboard to see scan stats.
